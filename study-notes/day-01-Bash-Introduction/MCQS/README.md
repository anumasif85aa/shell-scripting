# Bash Scripting Day 1 — Introduction MCQ Quiz

An interactive beginner-level assessment covering the foundational concepts taught in Day 1 of the Bash scripting course.

> **25 questions · 20-minute timer · 80% passing score**

## Take the live quiz

[Start the Bash Scripting Day 1 Quiz](https://khalidkhan.me/mcqs/bash-scripting/Bash-Scripting-Day-01-Introduction-MCQ-Quiz.html)

## Topics covered

- Shell and Bash fundamentals
- Terminal versus shell
- Bash scripts and shebang lines
- Linux architecture: user, shell, kernel, and hardware
- Safe Linux practice environments
- Machine and environment information
- Essential commands such as `whoami`, `hostname`, `uname`, `pwd`, `ls`, and `mkdir`
- Vim and Nano editor basics
- Script permissions and execution

## Quiz features

- 25 multiple-choice questions
- 20-minute countdown timer
- Automatic submission when time expires
- 80% passing requirement
- Immediate score and result summary
- Correct, incorrect, and unanswered counts
- Short explanation for every answer
- Topic-by-topic performance review
- Unanswered-question confirmation
- Best score saved in the browser
- Questions and answer choices shuffled on every attempt
- Mobile-friendly and print-friendly design

## How to use

1. Open the live quiz link.
2. Answer all 25 questions.
3. Select **Submit Quiz** before the timer expires.
4. Review the highlighted answers and explanations.
5. Practise weak topics in your terminal.
6. Select **Reattempt & Shuffle** to try a new order.

## Run locally

Download the following file and open it in any modern web browser:

```text
Bash-Scripting-Day-01-Introduction-MCQ-Quiz.html
```

On Linux:

```bash
xdg-open Bash-Scripting-Day-01-Introduction-MCQ-Quiz.html
```

The quiz is self-contained and does not require a web server, database, or installation.

## Recommended learning flow

```text
Study the lesson → Practise the commands → Attempt the quiz
→ Review explanations → Revisit weak topics → Reattempt
```
