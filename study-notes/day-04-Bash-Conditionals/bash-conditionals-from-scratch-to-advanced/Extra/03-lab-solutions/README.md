# Bash Conditionals — Lab Solutions

These solutions match the three student labs.

## How to use

1. Try each task yourself first.
2. Check syntax:

```bash
bash -n script-name.sh
```

3. Make the script executable:

```bash
chmod u+x script-name.sh
```

4. Run it:

```bash
./script-name.sh
```

Use the scripts for learning and comparison. More than one correct solution is possible.
