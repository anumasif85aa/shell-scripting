# Bash Error Handling — Lab Solutions

These solutions match all 18 tasks in the three student labs.

## Recommended Use

1. Attempt each task without the solution.
2. Check syntax with `bash -n`.
3. Test valid and invalid input.
4. Record the exit status.
5. Compare your output, status, and failure behavior with the solution.

A script is not fully tested until its failure paths are tested.
