# Bash Scripting — Output, Variables & User Creation MCQ Quiz

An interactive beginner-friendly assessment covering the Bash journey from command output and variables to safe Linux user creation and verification.

> **25 questions · 20-minute timer · 80% passing score**

## Take the live quiz

[Start the Output, Variables & User Creation Quiz](https://khalidkhan.me/mcqs/bash-scripting/Bash-Scripting-Output-Variables-User-Creation-MCQ-Quiz.html)

## Topics covered

- Standard output and standard error
- File descriptors for stdin, stdout, and stderr
- Exit status and checking `$?`
- Success status `0` and non-zero failure statuses
- Shebang lines and Bash script execution
- Single-line and multiline comments
- Variables and safe quoting
- User input with `read -r -p`
- Success chaining with `&&`
- Failure handling with `||`
- Safe Linux user creation with `useradd -m`
- Checking existing users before creation
- Exact account verification with `getent passwd`
- Accurate success and failure reporting

## Quiz features

- 25 multiple-choice questions

- Correct, incorrect, and unanswered totals

## How to use

1. Open the live quiz.
2. Answer all 25 questions.
3. Select **Submit Quiz** before the timer expires.
4. Review the highlighted answers and explanations.
5. Check the performance report for weak topics.
6. Practise those commands in a safe Linux lab.
7. Select **Reattempt & Shuffle** for a fresh order.

## Run locally

Download the following file and open it in any modern web browser:

```text
Bash-Scripting-Output-Variables-User-Creation-MCQ-Quiz.html
```

On Linux:

```bash
xdg-open Bash-Scripting-Output-Variables-User-Creation-MCQ-Quiz.html
```

The quiz is self-contained and does not require a web server, database, or installation.

## Safety note

Practise account-creation commands only in a personal Linux virtual machine, WSL lab, or another approved training environment. Validate the username, check whether the account already exists, quote variables, verify the result, and use elevated privileges carefully.
