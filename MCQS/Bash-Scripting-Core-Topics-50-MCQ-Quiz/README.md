## Important Bash Reminder

Before running a Bash script, check its syntax:

```bash
bash -n script.sh
```

Then run it:

```bash
chmod u+x script.sh
./script.sh
```

Always practise administrative scripting as a regular user unless a specific
command genuinely requires elevated privileges.
